# Quaternius Stylized Nature MegaKit (Standard)

Ironvale uses a curated subset of geometry from the Quaternius **Stylized Nature MegaKit** as its first external environment library.

- Creator: Quaternius
- Official pack: https://quaternius.com/packs/stylizednaturemegakit.html
- Pack mirror used by the guarded build to vendor the selected files: https://github.com/agentkaerf/FreeModels/tree/main/Stylized%20Nature%20MegaKit%5BStandard%5D
- Local license copy: `LICENSE.txt`

The build vendors only selected glTF geometry/buffer files needed by Ironvale rather than the entire pack. The original license text is preserved beside the assets.

Current curated models:
- `Rock_Medium_1`
- `Rock_Medium_2`
- `Rock_Medium_3`
- `CommonTree_1`
- `Pine_1`

These models are used as environment meshes over Rift's smooth visible terrain while the Rift block world remains the gameplay/collision representation underneath.
