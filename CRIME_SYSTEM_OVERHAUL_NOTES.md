# RiftCity Crime System Overhaul

## Patched
- Preserved the existing Nerve system and original 10 starting Nerve.
- Reworked crimes into live branching runs with 1–3 randomized situation stages.
- Added encounter shapes with 1, 2, and 3 options instead of identical decision cards.
- Added rare high-risk opportunities and mastery-gated events.
- Added Strength, Speed, and Dexterity-gated crime choices.
- Crime decisions now modify success chance, payout, Heat, arrest pressure, injury chance, bounty chance, loot odds, mastery gain, and XP.
- Added a player bounty value and active arrest charges to save data with backwards-compatible defaults.
- Arrests can record the committed crime and additional contraband-possession charges when applicable.
- Added injury outcomes on risky successful runs, critical failures, and some failed escapes.
- Expanded successful crime loot to include candy/consumables plus the existing contraband and collectible rarity drops.
- Rare choices can strongly multiply loot odds without removing each item's underlying rarity.
- Added live projected success / reward / loot / risk display during a crime run.
- Added responsive mobile styling for the branching crime interface.
